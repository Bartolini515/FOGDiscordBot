# FOGDiscordBot

FOGDiscordBot is a custom Discord bot built for the FOG community server, focused on simplifying mission organization and improving overall server management. The bot is built with the discord.py library and uses SQLite for persistent data storage.

Its main feature is a mission slotting system that allows members to assign themselves to available roles during events and operations. The bot tracks signups, slot availability, and related mission data directly in an SQLite database, making the process more reliable and easier to manage compared to previous manual systems.

The project was created as a quality of life improvement for the server, replacing older workflows with a more automated and structured solution. In addition to mission slot management, the bot includes several utility and moderation-oriented features tailored specifically to the needs of the FOG Discord community.

## Features

- Self-assignment to mission/event slots
- Persistent SQLite database integration
- Automated tracking of mission participation
- Discord server utility and management features
- Built specifically for the FOG community workflow
- Designed with scalability and maintainability in mind
- Powered by Python and discord.py

## Tech Stack

- Python
- SQLite
- discord.py

## Purpose

This bot was developed specifically for the FOG Discord server to improve mission organization, reduce manual management, and provide a smoother experience for community members and administrators.
